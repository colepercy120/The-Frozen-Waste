############################################################
##### UMLI CHARACTER LINES - 6700 TO 7200 ###################
############################################################
# Culture: umli
# Faith: faith_khazad
# Base-stat total (diplomacy + martial + stewardship +
# intrigue + learning + prowess): 20-30 for every character.
# Umli are short humans, NOT Dwarves:
# - most characters use trait = dwarf for stature
# - lifespans are generated on ordinary human scales
# - no long-lived/dwarven lifespan treatment is used
#
# Five principal dynastic lines:
# 1. House Motsognir   - ROYAL LINE
# 2. House Dvalin
# 3. House Brokkr
# 4. House Andvari
# 5. House Nori
#
# Main-line couples have 2-4 children.
# Most spouses are lowborn Umli; a small number of marriages
# intentionally intermingle the five houses.
############################################################
